## Siti che faremo

2. **Guida anime e manga**: schede di serie e consigli per genere e per chi inizia (testi originali).
3. **Community**: forum o gruppo, eventi, fiere e cosplay, newsletter.
4. **Shop**: merchandising ufficiale e prodotti con licenza, gadget originali (base `ecommercealfolio1`).
